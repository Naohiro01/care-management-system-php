# 利用者管理システム(PHP+MySQL版)

介護施設向けの利用者情報を管理する社内システムを想定したWebアプリです。
静的版(HTML/CSS/JS)をベースに実際にデータベースと連携して動作するバックエンドを実装しました。

## 制作の背景

静的版を制作する過程で「検索するたびにページ全体を読み込む必要があるのか」という疑問を持ちました。
その答えを調べ、実装を通じて理解するためにPHP･MySQL･Fetch APIを用いてバックエンドから作り直したのが本プロジェクトです。

## 対象ペルソナ

入職数年目のパソコン操作に不慣れな介護職員。(静的版と同様)

| 課題 | 静的版の実装 |　PHP版での解決
|---|---|---|
| データがJS内にベタ書き | 配列で直書き | MySQLでデータベース管理 |
| SQL文字列の直接埋め込みリスク | (該当なし) | prepare文+プレースホルダで対策 |
| 検索のたびにページ全体を再描画 | filter()のみ | Fetch APIで検索結果のみ部分更新 |
| パスワードを生の文字列で比較 | admin/1234を直接比較 | password_hashでハッシュ化して照合 |
| ログイン状態の管理 | sessionStorage(ブラウザ側のみ) | PHPセッション($_SESSION、サーバー側管理) |

## 機能一覧

- ログイン認証(パスワードのハッシュ化) 
- セッション管理(未ログイン時は自動的にログイン画面へ) 
- 利用者一覧表示(データベースから全件取得) 
- 検索･絞り込み(名前･ふりがな･介護度･性別･担当者･Fetch APIによる非同期処理) 
- 利用者詳細表示(IDを指定してデータベースから1件取得) 
- ログアウト(セッション破棄)

## データベース設計

**userテーブル**:利用者情報(氏名･年齢･性別･生年月日･介護度･担当者･住所･電話番号･緊急連絡先･利用開始日･利用曜日･備考等)

**userテーブル**:管理者ログイン情報(ユーザー名･ハッシュ化済みパスワード)

## セキュリティ面で意識した点

- パスワードは'password_hash()'でハッシュ化して保存し、平文では一切扱わない
- 全てのSQL文は'POD::prepare()とプレースホルダ('?')'を使用し、SQLインジェクションを防止
- 画面への出力時は'htmlspecialchars()'を徹底し、XSS(クロスサイトスクリプティング)を防止
- データベースの接続情報(パスワード)は'.env'ファイルに分離し、Gitの管理対象から除外('.gitnore')

## 使用技術

- PHP(POD使用)
- MySQL
- HTML / CSS / JavaScript(Fetch API)
- 開発環境:MAMP(Mac)/XAMMP(Windows)

## ページ構成
